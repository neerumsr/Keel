# Getting help

| You need | Go to |
|---|---|
| Install, first request, keys | [Quickstart](docs/quickstart.md) and [Help guide](docs/help-guide.md) |
| Run it in Docker, Kubernetes or the cloud | [Deploy](docs/deployment.md) |
| A question that the docs do not answer | GitHub Discussions on this repository |
| A bug | A GitHub issue with the bug template (include the model id from the response) |
| A wrong or unsafe decision | A GitHub issue with the model-quality template. Remove private text from `state` first |
| A security problem | Private report only, see [SECURITY.md](SECURITY.md) |

Keel is maintained by volunteers. There is no SLA. Issues with a minimal request body that reproduces the problem get
answered first.
