# Files to upload to the Hugging Face model repo

Target repo: `neerumsr/keel-3` (model). If Keel-3 is not promoted by release day, upload Keel-2 to
`neerumsr/keel-2` from `models/keel-2` instead and edit `hf/README.md` as noted at its top.

`models/keel-3` did not exist when this list was written (2026-10-29). Run step 1 below again
after promotion and update the list if the file set differs.

teacher models, training data (`training/data/**`), or public-benchmark eval subsets.

## Steps

1. `Get-ChildItem models\keel-3 -Recurse -File` and compare with the table.
2. Confirm `keel.json` `id` is `decider-3.0.0` and the README numbers match `docs/benchmarks`.
3. Run `node scripts/oss-audit.mjs` (must be clean of high/medium).
4. Review and run `hf/upload.ps1` by hand (it is fully commented out on purpose).
